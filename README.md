# O1 多智能体团队测评代码

这里整理了我们在 **LiveCodeBench** 和 **HLE** 上使用的测评代码，方便在其他服务器上查看、适配和复跑。

## 代码目录

| 文件夹 | 内容 |
| --- | --- |
| [livecodebench/](livecodebench/) | 编程任务测评，生成代码后使用官方测试判题 |
| [hle/](hle/) | 综合知识与推理任务测评，包含分层抽样、解题和独立评分 |

两个文件夹均包含 O1 框架代码、配置示例和运行入口，可以单独取用。

## 实验配置

- **框架：** Orchestra-O1。
- **主模型：** `Orchestra-o1-8B-all-ourdata`，负责规划和汇总。
- **子模型：** `Qwen3-Omni-30B-A3B-Instruct`，负责执行子任务和调用工具。

运行前需要自行准备模型服务和官方数据，具体步骤见各文件夹说明。仓库**不包含数据集、模型权重、API 密钥或实验输出**，也不会默认启动付费评分 API。

本仓库为历史实验代码的整理版，迁移到新服务器后需先完成配置与预检。

# HLE 测评

使用 O1 多智能体团队回答综合知识与推理题，支持代码执行、搜索、网页/PDF 读取和 Omni 图像分析。答案生成与最终评分分开运行。

## 主要文件

| 文件 | 用途 |
| --- | --- |
| `stratified_sample.py` | 按学科、模态和题型分层抽样 |
| `run_hle_o1.py` | 解题主入口 |
| `hle_runtime.py`、`hle_team_base.py`、`hle_schemas.py` | 工具、模型调用与动作格式适配 |
| `hle_judge.py` | 独立答案评分 |
| `framework/` | O1 框架源码 |
| `.env.example`、`run.sh` | 配置示例与启动脚本 |

## 如何运行

1. 准备 Linux、Python 3.12、Docker 和主、子模型服务。
2. 安装依赖，按 `.env.example` 填写本机路径、接口及搜索配置。
3. 从官方获取已授权的 HLE 数据，运行抽样脚本，并准备容量预检等配置。
4. 加载配置，执行 `bash run.sh` 开始解题；评分需另行配置裁判并显式启动。

完整命令和配置要求见 **[部署说明](SETUP.md)**；数据来源为 **[官方仓库](https://huggingface.co/datasets/cais/hle)**。

## 实验记录

历史实验从2,500题中分层抽取500题，已确认答对20题，按全部样本计为 **4.0%**，另有2题缺少评分。该结果不是全量 HLE 成绩。

仓库不附带题目、答案、权重或密钥。**评分默认关闭**；如使用本地裁判，需注明与历史在线裁判的区别。迁移后应先验证工具、模型容量和评分流程。
